# План на день

Простой список задач на HTML, CSS и обычном JavaScript. Данные загружаются из [DummyJSON Todos API](https://dummyjson.com/docs/todos).

## Запуск

Нужен Python 3 для локального HTTP-сервера. В терминале из папки проекта выполните:

```powershell
py -m http.server 8000
```

Затем откройте в браузере <http://localhost:8000>. Остановить сервер можно сочетанием `Ctrl+C`.

## Данные

DummyJSON имитирует создание, изменение и удаление. Результаты операций сохраняются в памяти открытой страницы: новые задачи получают локальные отрицательные ID и далее редактируются без запросов. После перезагрузки страницы все изменения сбросятся, а список загрузится снова из API.
